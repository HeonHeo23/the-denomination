# Crisis Concepts Across Eras

Twelve crisis ideas for a fictional Christian denomination. Consequence suggestions use supported Resource and Grudge effects. Node labels are conceptual placeholders for Scenario nodes, and threshold values should be chosen within each node's domain.

Game Over prerequisites use runtime node predicates. Each suggested group requires every listed predicate to hold. Separate groups can express alternative qualifying paths.

## Early House-Church Network

### 1. Gatherings Raided

- **Background:** Local persecution and vulnerable house churches.
- **Prerequisites:** One group. Official scrutiny active AND community trust at-most a Scenario threshold.
- **Stages:** Warning through a disrupted gathering. Escalation through questioning, member withdrawal, and broken coordination.
- **Consequences:** Warning stage reduces an authority Resource. Later stages apply negative Grudges to trust and cohesion.
- **Recovery:** Restore communication and local trust. Add a positive trust Grudge.
- **Game Over:** The house-church network dissolves into isolated communities.

### 2. Teachers Divide the Network

## Design Fit

Each Crisis pitch represents a Scenario-authored [Game Over](GAME_DESIGN.md#game-overs) trajectory. Prerequisites sustain the crisis across turns. Stages carry narrative and mechanical consequences. When no group remains satisfied, recovery applies. Qualification through the terminal turn produces the Game Over report.
